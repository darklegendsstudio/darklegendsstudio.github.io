# Dark Legends Studio Web v1.0

Base estática de la web de Dark Legends Studio preparada para GitHub Pages.

Esta versión conserva la arquitectura genérica de HISTORIAS introducida en v0.9 y añade soporte visual para el contenido administrado por DLS Stories Publisher v1.1:

- PERSONAJES muestra un estado vacío cuando todavía no hay fichas publicadas.
- La primera aparición de un personaje puede enlazar directamente al capítulo correspondiente mediante `primera_aparicion_enlace`.
- UNIVERSO muestra estados vacíos apropiados cuando aún no hay entradas o cuando un filtro no tiene resultados.

No es necesario cambiar los JSON existentes de ARKAXES. El Publisher v1.1 continúa usando la estructura ya compatible con esta web.
